# صندوق ورودی چندکاناله

صفحه **صندوق ورودی** (`/inbox`) همه مکالمات مشتری/سرنخ را از کانال‌های زیر در یک لیست واحد نشان می‌دهد:

| کانال | webhook / ارسال |
|--------|------------------|
| واتساپ | `/api/webhooks/whatsapp` |
| پیامک | `/api/webhooks/kavenegar/{orgSlug}` |
| ایمیل | `/api/webhooks/resend/{orgSlug}` |
| تماس (VoIP) | `/api/webhooks/voip/{orgSlug}` |
| تلگرام | `/api/webhooks/telegram/{orgSlug}` |
| اینستاگرام DM | `/api/webhooks/instagram/{orgSlug}` |

## پیکربندی

1. **تنظیمات → یکپارچه‌سازی‌ها** — کلیدها و webhook URL هر کانال
2. متغیرهای محیط سراسری (fallback) در [متغیرهای محیط](متغیرهای-محیط)
3. برای production اینستاگرام: Meta App Review برای `instagram_manage_messages`

## APIهای مفید

- `GET /api/inbox` — لیست thread (فیلتر `?channel=WHATSAPP`)
- `GET /api/inbox/{threadId}` — پیام‌های یک مکالمه
- `PATCH /api/inbox/{threadId}/assign` — تخصیص مسئول
- `GET /api/inbox/health` — وضعیت پیکربندی کانال‌ها
- `GET /api/inbox/stream` — SSE به‌روزرسانی (polling داخلی؛ UI با EventSource + fallback)
- `GET /api/inbox/customer/{id}/telegram|instagram` — thread لینک‌شده CRM
- `GET /api/inbox/lead/{id}/telegram|instagram` — thread لینک‌شده CRM

## تخصیص و KPI

- مدیر می‌تواند thread را به عضو تیم assign کند
- round-robin خودکار هنگام پیام ورودی (در صورت فعال بودن)
- badge خوانده‌نشده با `lastReadAt` — با باز کردن مکالمه پاک می‌شود
- KPI تیم در `/team` شامل متریک مکالمه و sentiment است
