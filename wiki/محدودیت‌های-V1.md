# محدودیت‌های V1

مواردی که عمداً کامل نشده‌اند یا نیاز به بهبود دارند.

## محصول

| محدودیت | توضیح |
|---------|--------|
| چند workspace همزمان در یک تب | یک org فعال در session؛ تعویض بدون logout از سوئیچر سایدبار |
| فرم/جدول یکدست | بخشی از UI هنوز یکپارچه‌سازی کامل ندارد |
| WebSocket دائمی | روی Vercel serverless deferred؛ inbox از SSE + reconnect استفاده می‌کند |

## پرداخت و کانال‌ها (بازار ایران)

| محدودیت | توضیح |
|---------|--------|
| درگاه فاکتور مشتری | **فعال** با کلیدهای زرین‌پال/آیدی‌پی در تنظیمات سازمان (`/pay/[token]` و پورتال) |
| خرید طرح اشتراک (billing) | درگاه آنلاین طرح هنوز «به‌زودی» — تغییر طرح می‌تواند دستی/دمو باشد |
| پیامک/واتساپ | ارسال واقعی وقتی Kavenegar / WhatsApp Cloud در org یا env پیکربندی شود؛ بدون کلید = noop |
| Meta App Review | ارسال/تأیید اپ واتساپ/اینستاگرام فقط از حساب Meta اپراتور |

## مؤدیان

| محدودیت | توضیح |
|---------|--------|
| API مستقیم مالیات | نیاز به گواهی حافظه مالیاتی — در محصول: خروجی JSON/XML + واسط |
| امضای رسمی | خارج از repo؛ اپراتور در نرم‌افزار واسط یا سامانه |

## دستیار هوشمند

| محدودیت | توضیح |
|---------|--------|
| قالب پاسخ | plain text |
| وابستگی سرویس | حالت degraded در قطعی LLM |
| ML آموزش‌دیده | تحلیل احساس lexicon + LLM اختیاری؛ pipeline آموزش مدل آینده است |

## فنی

| محدودیت | توضیح |
|---------|--------|
| آپلود روی Vercel | ذخیره‌سازی موقت serverless (S3 اختیاری) |
| backup ابری خودکار | زمان‌بندی خارج از repo |
| ممیزی WCAG رسمی | انجام نشده — بهبودهای a11y تدریجی |
