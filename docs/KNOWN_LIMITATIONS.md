# محدودیت‌های شناخته‌شده — V1

مواردی که عمداً در V1 کامل نشده‌اند یا نیاز به بهبود دارند. (به‌روز برای v0.12.0)

## محصول

| محدودیت | توضیح | اولویت پس از لانچ |
|---------|--------|-------------------|
| فرم‌های یکسان‌سازی‌نشده | همه فرم‌ها هنوز react-hook-form+zod نیستند | متوسط |
| جداول دستی | برخی لیست‌ها DataTable یکپارچه ندارند | پایین |
| WebSocket دائمی | روی Vercel deferred؛ inbox از SSE با reconnect استفاده می‌کند | پایین |
| چند workspace در یک تب | یک org فعال؛ سوئیچ بدون logout از سایدبار | طراحی آینده |

## دستیار هوشمند

| محدودیت | توضیح |
|---------|--------|
| markdown غنی | پاسخ plain text |
| وابستگی AI service | حالت degraded در قطعی سرویس |
| ML آموزش‌دیده | lexicon + LLM اختیاری؛ pipeline آموزش آینده |

## فنی

| محدودیت | توضیح |
|---------|--------|
| migration history | ممکن است baseline در حال تکمیل باشد |
| Prisma tenant middleware | انضباط در سرویس‌ها، نه middleware سراسری |
| backup خودکار cloud | اسکریپت pg_dump — زمان‌بندی خارج از repo |

## دسترسی‌پذیری

- بهبود focus و screen reader انجام شده؛ ممیزی رسمی WCAG انجام نشده
- کانبان با کیبورد پایه (`KeyboardSensor`) پشتیبانی می‌شود

## بازار ایران

- **درگاه فاکتور:** زرین‌پال/آیدی‌پی با کلید org فعال است
- **خرید طرح اشتراک:** ممکن است هنوز دستی/به‌زودی باشد
- پیامک/واتساپ اتوماسیون وقتی credentials پیکربندی شود ارسال می‌شود
- API مستقیم مؤدیان نیاز به گواهی حافظه مالیاتی دارد (خروجی JSON/XML + واسط آماده است)

## امنیت

- audit کامل SIEM نیست — `AuditEvent` سطح محصول
- rate limiting سطح edge ممکن است نیاز به تنظیم production داشته باشد

## ثبت مورد جدید

هنگام کشف محدودیت در پایلوت، این فایل را با تاریخ و شناسه مشتری به‌روز کنید.
